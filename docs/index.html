Installer Kyara Games

Le compagnon non officiel de kyara.games : cartes manquantes en gris avec ordre d'achat, albums complets masqués, doublons pendant les échanges, booster le plus rentable, classement entre amis.

Installation (2 minutes, une seule fois)

  1. Installe l'extension Tampermonkey

    C'est elle qui fait tourner le script Kyara Games et qui le met à jour.

    Chrome / Opera / Brave Firefox Edge

  2. Chrome, Edge, Brave : autorise les scripts

    Va dans chrome://extensions (ou edge://extensions, brave://extensions), clique sur Détails sous Tampermonkey et active Autoriser les scripts utilisateur. Si cette option n'existe pas, active plutôt le Mode développeur en haut à droite.

    Firefox : rien à faire.

  3. Installe Kyara Games

    Tampermonkey ouvre le script : clique sur Installer.

    Installer Kyara Games

  4. Ouvre kyara.games et connecte-toi

    Une seule fois : le script reprend ta session tout seul. Les réglages sont dans le menu du site, Plus → 設 Kyara Games.

    Aller sur kyara.games

Les mises à jour arrivent toutes seules par Tampermonkey. Tu veux aussi les notifications (boosters gratuits pleins, échanges, ventes…) et la fenêtre de l'extension ? Installe plutôt l'extension complète.

Android

  1. Installe Firefox

    Sur Android, Firefox accepte les extensions (Chrome, Brave et Samsung Internet non).

    Firefox sur le Play Store

  2. Ajoute Tampermonkey dans Firefox

    Ouvre ce lien dans Firefox et touche Ajouter à Firefox, puis Ajouter.

    Tampermonkey pour Firefox Android

  3. Installe Kyara Games

    Dans Firefox, touche le bouton : Tampermonkey affiche le script, touche Installer.

    Installer Kyara Games

  4. Ouvre kyara.games et connecte-toi

    Une seule fois. Les réglages : menu du site (☰) → 設 Kyara Games.

    Aller sur kyara.games

Les mises à jour arrivent toutes seules par Tampermonkey. Sur téléphone, pas de notifications : le script ne tourne que quand une page kyara.games est ouverte.

iPhone et iPad

  1. Installe l'app Userscripts

    Gratuite. Ouvre-la une fois après l'installation.

    Userscripts sur l'App Store

  2. Active-la dans Safari

    Réglages → Apps → Safari → Extensions → Userscripts : active Autoriser l'extension, puis autorise kyara.games (ou tous les sites).

  3. Installe Kyara Games

    Ouvre ce bouton dans Safari, touche l'icône des extensions dans la barre d'adresse (ᴀA ou la pièce de puzzle) → Userscripts, puis Installer.

    Installer Kyara Games

  4. Ouvre kyara.games dans Safari et connecte-toi

    Une seule fois. Les réglages : menu du site (☰) → 設 Kyara Games.

    Aller sur kyara.games

Userscripts vérifie les mises à jour du script. Pour forcer la dernière version, rouvre le bouton « Installer Kyara Games » et réinstalle.

Ce que ça ajoute

  • Cartes manquantesEn gris au lieu d'un « ? », avec leur prix et un bouton « Ordre d'achat ».
  • CollectionPuces Possédées / Manquantes, séries complètes et petites séries masquées, fiche en un clic.
  • ÉchangesBadges ×N et « Unique », filtre « Ses doublons », prix et écart de valeur à la confirmation.
  • Boosters rentablesLe booster le plus rentable pour une rareté, un perso ou un univers (menu Plus).
  • Classement entre amisFiltre « Amis » avec le podium et la liste du site.
  • Verrous malins« Bloquer sauf doublons » et dernier exemplaire verrouillé quand un doublon est en vente.
