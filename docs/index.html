Installer Kyara Games

Le compagnon non officiel de kyara.games : cartes manquantes en gris avec ordre d'achat, albums complets masqués, doublons pendant les échanges, booster le plus rentable, classement entre amis.

Installer sur PC

Ça prend 2 minutes et ça se fait une seule fois. Fais les étapes dans l'ordre et garde cette page ouverte jusqu'à la fin.

  1. Ajoute Tampermonkey à ton navigateur

    Tampermonkey est une extension gratuite. C'est elle qui fait marcher Kyara Games.

    1. Clique sur le bouton de ton navigateur ci-dessous. Le bon est marqué en vert « ton navigateur ».
    2. Une page s'ouvre : clique sur le bouton Ajouter à Chrome (ou Obtenir, ou Ajouter à Firefox).
    3. Une petite fenêtre te demande de confirmer : clique sur Ajouter l'extension.
    Chrome / Opera / Brave Firefox Edge

  2. Autorise Tampermonkey

    Tu es sur Firefox : tu n'as rien à faire ici, passe à l'étape 3.

    Chrome, Edge, Brave et Opera demandent une autorisation en plus.

    1. Copie cette adresse : chrome://extensions
    2. Ouvre un nouvel onglet (touches Ctrl + T), colle l'adresse dans la barre du haut (Ctrl + V) et appuie sur Entrée.
    3. Dans la liste, trouve Tampermonkey et clique sur Détails.
    4. Active l'interrupteur Autoriser les scripts utilisateur.

    Tu ne trouves pas « Autoriser les scripts utilisateur » ? Active plutôt l'interrupteur Mode développeur, en haut à droite de la page des extensions.

  3. Installe Kyara Games

    1. Clique sur le gros bouton rouge ci-dessous.
    2. Une page Tampermonkey s'ouvre avec écrit « Kyara Games » : clique sur Installer.
    Installer Kyara Games

    Tu vois une page pleine de texte et de code au lieu de Tampermonkey ? Tampermonkey n'est pas encore installé ou pas autorisé : refais les étapes 1 et 2, puis reclique sur le bouton rouge.

  4. Ouvre kyara.games et connecte-toi

    Connecte-toi comme d'habitude. Kyara Games démarre tout seul et une visite guidée te montre ce qu'il ajoute.

    Aller sur kyara.games

✔ Comment savoir que ça marche ?

Sur kyara.games, ouvre le menu Plus : tu dois y voir 設 Kyara Games (les réglages) et 学 Tutoriel. Sur la page Collection, les cartes que tu n'as pas s'affichent en gris au lieu d'un « ? ».

⬆ Mettre à jour

Tu n'as presque rien à faire.

  1. Quand une nouvelle version sort, un bandeau « Kyara Games … est disponible » apparaît sur kyara.games.
  2. Clique sur Mettre à jour dans ce bandeau.
  3. Une page Tampermonkey s'ouvre : clique sur Mettre à jour.
  4. Reviens sur kyara.games et recharge la page (touche F5). Une fenêtre te montre les nouveautés : c'est fini.

Le « ✕ » du bandeau le cache pendant 12 heures. Sans rien faire, Tampermonkey installe aussi la nouvelle version tout seul, environ une fois par jour.

Un problème ?

Rien ne change sur kyara.games. Recharge la page (F5). Vérifie l'étape 2. Puis clique sur l'icône Tampermonkey en haut à droite du navigateur (elle peut être cachée derrière la pièce de puzzle 🧩) : « Kyara Games » doit être activé.

Je ne vois pas le bandeau de mise à jour. Il apparaît au plus tard 15 minutes après la sortie d'une version, quand kyara.games est ouvert. Pour mettre à jour tout de suite, reclique sur le bouton rouge « Installer Kyara Games » de cette page : Tampermonkey te propose la nouvelle version.

Je veux aussi les notifications (boosters gratuits pleins, échanges, ventes…) et la fenêtre de l'extension. Elles viennent avec l'extension complète, plus longue à installer.

Pour que Tampermonkey cherche les mises à jour plus souvent : son tableau de bord → Paramètres (mode Avancé) → Mises à jour des scripts → la fréquence la plus courte.

Installer sur iPhone et iPad

Ça prend 3 minutes et ça se fait une seule fois. Fais les étapes dans l'ordre. Kyara Games marche seulement dans Safari, pas dans Chrome.

  1. Installe l'app Userscripts

    C'est une app gratuite. C'est elle qui fait marcher Kyara Games. Après l'avoir installée, ouvre-la une fois puis reviens ici.

    Userscripts sur l'App Store

  2. Active Userscripts dans Safari

    1. Ouvre l'app Réglages du téléphone.
    2. Touche Apps → Safari → Extensions → Userscripts.
    3. Active Autoriser l'extension.
    4. Juste en dessous, dans Autorisations, touche kyara.games (ou « Autres sites web ») et choisis Autoriser.

    Pas de menu « Apps » ? Sur les iPhone plus anciens : Réglages → Safari → Extensions.

  3. Installe Kyara Games

    1. Dans Safari, touche le gros bouton rouge ci-dessous.
    2. Une page pleine de texte s'ouvre : c'est normal.
    3. Touche l'icône ᴀA (ou la pièce de puzzle) à côté de l'adresse, en haut ou en bas de l'écran.
    4. Touche Userscripts, puis Installer.
    Installer Kyara Games

  4. Ouvre kyara.games dans Safari et connecte-toi

    Connecte-toi comme d'habitude. Une visite guidée te montre ce que Kyara Games ajoute.

    Aller sur kyara.games

  5. Une icône sur l'écran d'accueil (facultatif)

    Attention : une icône ajoutée en « app web » ouvre le site sans Kyara Games. Pour une icône qui marche :

    1. Dans Safari, sur kyara.games, touche Partager (le carré avec une flèche).
    2. Touche Sur l'écran d'accueil.
    3. Désactive « Ouvrir en tant qu'app web », puis touche Ajouter.

    Cette option n'existe pas sur ton iPhone ? Ajoute plutôt kyara.games aux Favoris de Safari (Partager → Ajouter aux favoris). Une ancienne icône « app web » peut être supprimée puis ajoutée à nouveau.

✔ Comment savoir que ça marche ?

Sur kyara.games, ouvre le menu du site ☰ : tu dois y voir 設 Kyara Games (les réglages). Sur la page Collection, les cartes que tu n'as pas s'affichent en gris au lieu d'un « ? ».

⬆ Mettre à jour

  1. Quand une nouvelle version sort, un bandeau « Kyara Games … est disponible » apparaît sur kyara.games.
  2. Touche Mettre à jour : la page pleine de texte s'ouvre, c'est normal.
  3. Touche ᴀA (ou la pièce de puzzle) → Userscripts → Installer.
  4. Reviens sur kyara.games et recharge la page (flèche ⟳ à côté de l'adresse). Une fenêtre te montre les nouveautés : c'est fini.

Pas de bandeau ? Il apparaît au plus tard 15 minutes après la sortie d'une version, quand kyara.games est ouvert. Tu peux aussi retoucher le bouton rouge « Installer Kyara Games » de cette page à tout moment.

Un problème ?

Rien ne change sur kyara.games. Vérifie que tu es dans Safari (pas Chrome, pas une icône « app web »), puis refais l'étape 2 : Userscripts doit être autorisé pour kyara.games.

Je ne trouve pas « Userscripts » en touchant ᴀA. L'extension n'est pas activée : refais l'étape 2.
